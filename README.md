# AGILE | Secure Collaboration Suite 🚀

An open-source, secure, and real-time Agile toolset consisting of **Scrum Poker** and **Retrospective** boards. Built with a "Red Team" mindset to prevent tampering and ensure fair play.

🔗 **Live Demo:** [https://agile-suite.vercel.app/]


## 🔥 Features

- **🛡️ Enterprise Security:** Includes an active `SecurityLayer` that blocks Context Menu, F12, DevTools, and employs anti-debugging traps.
- **🃏 Scrum Poker:** Real-time estimation with Fibonacci cards. Features a "Lobby" system and backlog management.
- **🚀 Retrospective:** Start/Stop/Continue boards with live voting and instant sync.
- **🌗 UI/UX:** Fully responsive design with Dark/Light mode support via Tailwind CSS.
- **⚡ Tech Stack:** Next.js 14 (App Router), Firebase Firestore, Tailwind CSS.
